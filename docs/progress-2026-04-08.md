# smolclaw Progress Report — 2026-04-08

## Summary

Security hardening, sandbox re-enablement, and 9 optimization fixes from deep log analysis. Cost per successful run halved ($4.17 → $2.25). Local model testing revealed 7-9B models can't handle multi-step agentic workflows.

## Changes (10 commits)

### Security & Sandbox
- **Secret redaction in action log** — error snippets now go through `sc_redact_secrets()`
- **XML sandboxing** — scratchpad/action log wrapped in `<context type="...">` tags
- **Sandbox re-enabled** — added `~/.local` to Landlock RX paths for user-installed tools (cmake via pip)
- **Exec allowlist fix** — handle shell redirects (`2>&1`) and absolute paths (`/home/user/.local/bin/cmake`)
- **Hardening** — bounds checks, UTF-8-safe truncation, OOM-safe realloc, PATH_MAX buffers

### Compaction & Performance
- **Fixed auto-compaction token comparison** — was comparing cumulative tokens (never decreases) against window. Now uses per-call `last_prompt_tokens` from API response. This was why compaction triggered 27x without effect.
- **Summarization retry with backoff** — 3 attempts with 2s/4s backoff. Logs HTTP status (429 rate limit vs API error). Prevents circuit breaker from tripping on transient failures.
- **Configurable `summary_model`** — new config field for cheaper/faster summarization. GLM-4.7-Flash ($0.06/$0.40) instead of GLM-5.1 ($1.40/$4.40) = 23x cheaper.
- **`--force-with-lease` allowed** in git tool (safe push for diverged branches)
- **Blocked exec command logging** — logs the actual command (truncated 200 chars) at WARN level
- **Smart continuation nudge** — detects CMakeLists.txt in workspace, suggests specific cmake command

## Local Model Testing

Tested qwen3.5:9b and qwen2.5-coder:7b via Ollama on RTX 3050 (8GB):
- **qwen3.5:9b**: 299s per iteration, narrates instead of making tool calls. Unusable.
- **qwen2.5-coder:7b**: Fast (4-7s) but calls wrong tools, misses required params. Can't complete workflow.
- **Conclusion**: 7-9B models lack agentic capability for multi-step workflows. Need 27B+ or purpose-built agentic local models.
