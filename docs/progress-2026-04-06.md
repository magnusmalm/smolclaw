# smolclaw Progress Report — 2026-04-06

## Summary

Implemented a 4-layer defense against "compaction amnesia" — the problem where context summarization causes agents to forget what files they modified, what git operations they performed, and what workflow steps they completed. This was the #1 blocker for multi-step agentic workflows (clone -> edit -> build -> commit -> push).

## Changes

### 1. Observation Masking (`src/agent.c`)
Replaced the existing `compress_old_tool_results` context transform (only compressed >10KB results) with `mask_old_observations` — all tool results >200 bytes older than 6 messages are replaced with structured placeholders:
```
[tool_result: read_file("src/server.c") -> ok, 48263 bytes, 1487 lines]
```
New helpers: `find_tool_call_for_id()` scans backward to find matching tool call metadata, `summarize_tool_arg()` extracts the key argument (path, command, query) for the placeholder.

### 2. Action-Only Compaction (`src/agent_session.c`)
Modified the summarization transcript builder to preserve full tool-call descriptions but compress tool-result content to metadata. The summarizer LLM now sees what the agent *did* rather than what tools *returned*. Budget calculation uses compressed size (~80 bytes) for tool results instead of raw content size, allowing more tool interactions to be included in the transcript.

### 3. Scratchpad Tool (`src/tools/scratchpad.c`, `src/context.c`)
New `note` tool writes to `{workspace}/state/scratchpad.md` (max 2048 bytes, overwrite semantics). Content is read fresh from disk and injected into the system prompt on every LLM call, surviving compaction entirely. Also injected into the post-compact boundary message.

### 4. Automatic Action Log (`src/agent_turn.c`, `src/context.c`)
Auto-appends a one-line summary after each tool execution to `{workspace}/state/action_log.txt`:
```
[iter 1] git(clone) -> ok (27 bytes)
[iter 5] edit_file(myproject/src/store.h) -> ERROR (56 bytes)
[iter 18] exec(cat myproject/src/server.c) -> ok (10034 bytes)
```
Rolling 2KB cap with automatic head truncation. Injected into system prompt as "## Action Log (auto-recorded)".

## Research Context

Design informed by:
- JetBrains "Complexity Trap" paper (NeurIPS 2025): observation masking matches LLM summarization quality at half cost
- Factory.ai evaluation: artifact tracking scores 2.2-2.5/5.0 across all compression methods
- CAT framework (arxiv 2512.22087): structured context workspace with agent-managed memory
- OpenHands condenser system: pluggable compression strategies
