# smolclaw Progress Report — 2026-04-07

## Summary

Added continuation nudge and error snippet capture to close the build gap in multi-step agent workflows. The nudge prevents premature turn ending when the agent hasn't built yet. Error snippets extract compiler diagnostics from failed exec calls and include them in the action log, so downstream agents (fixers) get exact error context via system prompt injection.

## Changes

### Continuation Nudge (`src/agent_turn.c`, `src/agent_internal.h`)
When the agent responds with text (ending the turn) but the action log shows file edits without any exec/build call, a nudge message is injected: "You have not built the code yet. Run the build command now." The iteration loop continues instead of ending.

- Only triggers once per turn (`nudge_count` field in `sc_turn_ctx_t`)
- Only after 5+ iterations (avoids nudging simple Q&A turns)
- Excludes read-only exec calls (cat, ls, grep) from the "has exec" check

### Error Snippet Capture (`src/agent_turn.c`)
When a tool call returns an error, the action log now extracts relevant diagnostic lines from the tool output. Matches patterns: `error`, `fatal`, `note:`, `undefined`, `undeclared`. Capped at 500 bytes per entry, long lines truncated at 200 chars.

Before: `[iter 10] exec(cmake ...) -> ERROR (2215 bytes)`
After:
```
[iter 10] exec(cmake ...) -> ERROR (2215 bytes)
  src/main.c:102: error: too many arguments to function 'sc_chat_server_run'
  src/server.h:27: note: declared here
```

Log cap bumped from 2KB to 4KB to accommodate error context.
